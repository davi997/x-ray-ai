# مشروع تشخيص الأشعة بالذكاء الاصطناعي

موقع بيرفع المستخدم عليه صورة أشعة (صدر أو مخ) والنموذج يقول: سليمة أو اسم المرض.

## التشغيل (مرة واحدة تجهّز، وبعدها أمر واحد)
```
python -m venv venv
venv\Scripts\activate        # على ويندوز  |  على ماك/لينكس: source venv/bin/activate
pip install -r requirements.txt
python app.py
```
افتح المتصفح على: http://127.0.0.1:5000

أول تشغيل بيحمّل النماذج من الإنترنت (حوالي 350 ميجا لكل نموذج) وبعدها بتشتغل من الجهاز. مش محتاج كارت شاشة.

## النماذج المستخدمة (جاهزة من Hugging Face)
- الصدر: `lxyuan/vit-xray-pneumonia-classification` (Pneumonia / Normal)
- المخ: `DunnBC22/vit-base-patch16-224-in21k-Brain_Tumors_Image_Classification`

لو عاوز تبدّل نموذج، غيّر الـ ID في قاموس `MODELS` أعلى ملف `app.py` وخلاص. أسماء النتائج بتتقرأ من النموذج نفسه، وترجمتها للعربي في قاموس `AR`.

## ملاحظات مهمة
- النماذج دي متدرّبة على داتا سيت عامة وأدق ما تكون على صور شبهها. مش بديل عن الطبيب.
- الموقع بيقبل JPG/PNG (مش DICOM).
- لو عرضت المشروع على لجنة، اذكر إن النتيجة "مساعدة تعليمية" مش تشخيص طبي.
